# Web Prototype

This folder contains the first software prototype for the Smart Solar-Powered E-Bike Sharing Network.

## What it demonstrates

- E-bike availability
- Battery-level monitoring
- Charging-station status
- Solar generation display
- Simulated ride start/end
- Simulated ride timer
- Responsive web interface
- Offline operation with no external libraries

## Important

This is a **conceptual software prototype**. It is not connected to real e-bikes, GPS hardware, IoT sensors, a cloud database, payment systems, or a charging station.

The project's original concept proposes HTML5, CSS3 and JavaScript for the prototype, with IoT/GPS and microcontrollers such as Arduino or ESP32 for a future real deployment.

## Run locally

Open `index.html` in a web browser.

No server or internet connection is required.
